# Tank171 Hill Drive

Prototipe game mengemudi bukit 2D berbasis HTML Canvas, dibuat untuk diuji di browser sebelum mempertimbangkan APK Android.

## Status

- [x] Halaman prototipe awal `index.html`
- [ ] Pengujian gameplay dan perbaikan fisika
- [ ] Koin dan pickup bahan bakar yang divalidasi
- [ ] Garasi dan penyimpanan diuji
- [ ] Uji layar sentuh dan orientasi lanskap
- [ ] Pembungkus Android / APK (belum dimulai; perlu persetujuan setelah tes browser)

**Penting:** prototipe ini belum dianggap lolos pengujian. Jangan jalankan build APK dulu.

## Uji browser

1. Buka **Settings → Pages**.
2. Pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, lalu simpan.
3. Buka URL Pages yang diberikan GitHub pada desktop dan ponsel.
4. Uji GAS/REM tahan-tekan, fisika di bukit, pengambilan koin dan jeriken, game over, garasi, pembelian upgrade, simpan/muat progres, restart, dan jeda.
5. Catat bug dengan langkah reproduksi sebelum lanjut.

## Lingkup target MVP

- Mobil off-road 2D dan medan berbukit
- Kontrol GAS/REM
- Koin dan bahan bakar
- Garasi: mesin, ban, suspensi, tangki
- Jeda, game over, restart, rekor dan progres lokal

## Batasan

Ini prototipe awal untuk evaluasi, bukan salinan Hill Climb Racing. Visual, fisika, dan sistem pickup perlu divalidasi dan disempurnakan. Tidak ada build Android atau workflow APK pada tahap ini.
